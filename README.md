# 海龟汤小镇 · 互动推理游戏

一个纯前端、可离线的海龟汤（情境推理 / Lateral Thinking）互动网站。玩家在站内扮演主持人，通过不断地向「网站」提问（是 / 否 / 是也不是 / 不重要），逐步推理出汤底。

## 功能
- 收录大量海龟汤题库（白汤 / 红汤 / 搞笑沙雕 / 灵异变格 / 温情，按难度与汤种分类）。
- 与「主持人」实时问答互动，自带提示、灵感提问、推理记录。
- 每锅汤有各自的建议提问次数与「核心真相」数量，推理出全部关键情节即通关。
- 汤库支持按难度 / 汤种 / 标签 / 游玩状态 / 收藏 / 关键词搜索筛选。
- 私房汤：本机收藏与游玩（数据保存在浏览器 localStorage）。
- 收藏、分享（可勾选分享的具体进度 + 生成直达链接）。
- 在线投稿收集表（腾讯文档）。

## 运行
纯静态站点，直接用浏览器打开 `index.html` 即可；或部署到任意静态托管（GitHub Pages / Cloudflare Pages 等）。
